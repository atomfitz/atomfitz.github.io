Privacy Policy: OMR Minecraft Server Backup

Effective 25 November 2026

Who runs this app

OMR Minecraft Server Backup is a private backup tool run by the operator of the Orbiting Meadows (OMR) Minecraft server. It is not offered to the public. The only Google Account it connects to is the operator's own.

Google user data the app accesses

  • Google Drive, through the drive.file scope only. This lets the app see and change only the files and folders it created. It cannot see, open or change any other file in the Drive.
  • Drive storage figures (total and used space), read before uploads.
  • The connected account's email address, read once when access is granted, to confirm which account was connected.

How the app uses that data

  • It creates one folder for backups and uploads compressed backups of the server's files into it, checking each upload against its checksum.
  • It lists the files in that folder and permanently deletes older backups on the retention schedule below. It deletes only backups it uploaded.
  • It uses the storage figures only to check that a backup fits and to warn the operator when space is low.

What the backups contain

Each backup is a copy of the server's own files: world data, configuration, plugin data and server logs. These can include Minecraft player information such as usernames, player IDs (UUIDs), in-game data, chat and command logs, and connection IP addresses. Backups are stored only in the operator's private Google Drive and are not shared.

Storage and security

  • The app keeps a Google refresh token on the server computer, encrypted with Windows Data Protection so that only the operator's Windows account on that computer can use it. Short-lived access tokens are never saved.
  • Credentials are stored outside the server folder, so they are never included in a backup.
  • The app also keeps, on the server computer: the backup folder's Drive ID, the latest storage reading, the connected account's email address, and progress details used to resume an interrupted upload.

Retention

Backups less than 7 days old are all kept. Older backups are thinned: one per 12 hours up to 14 days old, one per day up to 60 days, one per week up to 182 days, and one per two weeks after that. The operator can delete any backup at any time.

Sharing

The app does not sell, share or transfer Google user data to anyone. It shows no ads, runs no analytics, and does not use the data to train or improve AI or machine-learning models. No AI agent accesses Google data through this app.

OMR Minecraft Server Backup's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from the Google Account's third-party connections page. Removing it stops all uploads and deletions; backups already in Drive stay there until deleted.

Changes

Changes to this policy are posted on this page with a new effective date.
