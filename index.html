OMR Minecraft Server Backup

Orbiting Meadows (OMR) Minecraft server

OMR Minecraft Server Backup is the private backup tool of the Orbiting Meadows Minecraft server. It is used only by the server operator, with the operator's own Google Account.

While the server is stopped, the tool takes a frozen copy of the server's files, compresses it, and uploads it to a folder in the operator's Google Drive. It checks each upload against its checksum, checks free Drive space before uploading, and removes older backups on a retention schedule. It can see only the files and folders it created.
